# (주)광덕건업 홈페이지

이동식주택·농촌체류형 쉼터·중고컨테이너를 안내하고, 전화 상담과 방문 문의로 이어지게 하는 회사 홈페이지입니다.

- 기술: **HTML · CSS · JavaScript 만 사용한 정적 사이트**
- 설치·빌드·서버·데이터베이스 없음. 외부 라이브러리 없음. (아이콘·로고는 직접 그린 SVG)
- 회원가입·결제·관리자·문의 폼 없음 (전화·지도 연결만)
- 확인용 주소: https://eunseokyu.github.io/gwangdeok-homepage/

---

## 1. 내 컴퓨터에서 보기

설치할 것이 없습니다. 저장소를 내려받은 뒤 **`index.html` 을 더블클릭**하면 브라우저에서 열립니다.

> 휴대폰 화면은 PC 크롬에서 `F12` → 왼쪽 위 휴대폰 모양 아이콘(기기 툴바)을 눌러 미리 볼 수 있습니다.
> 실제 휴대폰 확인은 GitHub 에 올린 뒤 위 확인용 주소로 합니다.

## 2. 페이지 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 홈: 첫 화면 → 주요 안내 바로가기 → 제품(분류 버튼) → 시공 사례 → 제작·설치 과정 → 자주 묻는 질문 → 연락처·오시는 길 |
| `products.html` | 제품 안내. `?category=mobile-home` / `shelter` / `container` 를 붙이면 그 분류가 선택된 상태로 열림 |
| `products/<제품>.html` | 제품 상세 (아래 ‘제품 상세 페이지 구성’ 참고) |
| `cases.html`, `cases/<사례>.html` | 시공 사례 목록·상세 |
| `process.html` | 제작·설치 과정, 비용 구성, 상담 전 준비물, 관련 질문 |
| `about.html` | 회사 안내·연락처·오시는 길(`#location`): 주소 복사, 네이버·카카오·구글 지도 링크 |
| `404.html` | 없는 주소로 들어왔을 때 보이는 안내 |
| `check.html` | **공개 전 확인 목록 (내부용)**. 메뉴에 연결되어 있지 않습니다 |

모든 페이지 공통: 머리글(PC 메뉴·대표전화 / 모바일 ‘메뉴’ 버튼과 제품 분류 바로가기), 바닥글, 모바일 하단 고정 메뉴(제품 보기 · 오시는 길 · 전화 상담), ‘본문 바로가기’ 링크.

### 제품 상세 페이지 구성

1. **이름과 핵심 요약**: 대표 사진, 제품 종류와 이름, 특징 한 문장, 외형 크기·실내 면적·공간 구성·가격, 전화 버튼
2. **페이지 안 바로가기**: 제품 소개 / 사진 / 평면 / 기본 사양 / 선택 옵션 / 가격·상담 (모바일 2열 × 3줄)
3. **어떤 생활을 위한 집인가요**: 쓰기 좋은 경우, 공간 구성과 생활상의 장점, 다른 평면이 맞는 경우
4. **사진으로 공간 살펴보기**: 공간 이름·설명, ‘선택 옵션 적용’ 표시, 누르면 크게 보기 (이전·다음·닫기·방향키·ESC)
5. **평면과 크기**: 평면도(크게 보기), 외형·실내·다락·데크를 나눈 크기와 산정 기준, 공간별 구성
6. **기본 사양**: 7개 묶음(구조·골조 / 지붕·외장 / 단열·방수 / 창호·현관 / 바닥·벽·천장 / 주방·욕실 / 전기·급배수·냉난방), 용어 풀이
7. **내 생활에 맞춰 바꿀 수 있는 부분**: ① 기본 제공 ② 선택 옵션(범위·차이·비용·제작기간) ③ 비용·기간 검토가 필요한 개별 변경
8. **가격과 상담**: 제품 가격·적용 사양·부가세, 가격 포함 범위, 제작·설치 일정, 상담 전 준비할 정보, 전화 버튼
9. 관련 시공 사례

## 4. 내용 바꾸는 방법

데이터 파일은 메모장이나 VS Code 로 열어 **따옴표(" ") 안의 글자만** 바꿉니다. 쉼표(,)와 괄호는 지우지 마세요.
바꾼 뒤 `index.html` 을 열어 화면이 그대로 나오는지 확인합니다. 화면이 비면 쉼표·따옴표가 빠졌을 가능성이 큽니다.

### 사진 넣기
1. 사진을 `images/products/`(제품) 또는 `images/cases/`(사례)에 넣습니다.
   - 파일 이름은 영문 소문자·숫자·하이픈 (예: `mobile-home-a-front.jpg`)
   - 가로 1600~2000px 정도의 JPG 로 줄여서 넣어 주세요. (원본 그대로 넣으면 휴대폰에서 느려집니다)
2. 사진의 가로·세로 픽셀을 확인합니다. (Windows: 파일 오른쪽 클릭 → 속성 → 자세히 / Mac: 파일 선택 후 ⌘+I)
3. `data/products.js` 의 `images` 에 적습니다.

```js
{
  src: "images/products/mobile-home-a-front.jpg",
  alt: "흰색 외벽과 데크가 있는 단층 이동식주택 정면",   // 사진에 보이는 내용을 구체적으로
  width: 1800,
  height: 1200,
  space: "외관",                                         // 외관·거실·주방·침실·욕실·수납·출입구 등
  caption: "현관 앞 데크에서 짐을 내려놓고 들어갈 수 있습니다.",
  optionsShown: ["데크"],                                // 사진에 들어간 선택 옵션 (없으면 [])
  // isDesignExample 줄은 지웁니다 (실제 사진이면 ‘디자인 예시’ 표시가 사라짐)
},
```

사진 파일이 없거나 이름이 틀리면 그 자리에 ‘사진 준비 중’이 표시되고 화면 모양은 유지됩니다.

### 제품 바꾸기 (`data/products.js`)
- 파일 맨 위에 모든 칸의 설명이 있습니다.
- 지금 3개는 **개발용 예시**(`isExample: true`)입니다. 첫 번째 ‘방 1개와 거실형 (예시)’는 상세 페이지 모양을 보여 주려고 모든 칸을 채운 예시이고, 수치는 ○, 가격은 ‘가격 상담’입니다.
- **모르는 값은 `null` 로 둡니다.** 화면에는 ‘상담 시 안내’로 보입니다. (예시 제품에서는 ‘회사 확인 필요’로 보입니다)
  ‘포함’, ‘별도’, 기간, 성능을 추측해 적지 마세요.
- 면적은 `size.interior` 한 곳에만 적습니다. 제품 카드와 상세 페이지가 같은 값을 씁니다.
- 가격: `{ kind: "consult" }`(가격 상담) / `{ kind: "fixed", amount: 32000000, vat: "included", appliesTo: "기본 사양 기준" }` / `{ kind: "from", ... }`(~원부터)

### 제품 추가하기
1. `data/products.js` 에서 비슷한 제품 하나를 `{` 부터 `},` 까지 복사해 붙여 넣고 내용을 바꿉니다. `slug` 는 새 영문 이름으로 (예: `mobile-home-b`).
2. `products` 폴더의 HTML 파일 하나를 복사해 이름을 `mobile-home-b.html` 로 바꿉니다.
3. 새 파일에서 세 군데를 바꿉니다: `<title>`, `og:title`·`description`(공유 미리보기 글자), 그리고 `data-slug="mobile-home-b"`.

> 제품마다 작은 HTML 파일을 두는 이유: 카카오톡 공유 미리보기와 검색 결과에 제품 이름이 제대로 나오게 하기 위해서입니다.

### 시공 사례 바꾸기 (`data/cases.js`)
- 지금 3개는 **개발용 예시**입니다. 실제 사례로 바꾸거나 지우세요. 사례를 추가할 때는 제품과 같은 방법으로 `cases` 폴더에 HTML 파일도 하나 만듭니다.
- 지역은 공개 가능한 범위만 (예: `"충남 천안"`). 번지·마을 이름·고객 이름 금지.
- 사진에 얼굴·차량 번호판·문패·주소가 보이면 가리거나 다른 사진을 쓰세요. 생성 이미지나 시안 이미지를 실제 사례 사진으로 쓰지 마세요.

### 자주 묻는 질문 (`data/faq.js`)
- 모든 답변이 **회사 확인 전 초안**(`needsReview: true`)입니다. 확인 후 `false` 로 바꾸면 ‘회사 확인 전 초안’ 안내가 사라집니다.

### 회사 정보 (`data/company.js`)
- `hours`(상담 시간), `representative`(대표자), `businessRegistrationNumber`(사업자등록번호)는 확인 전이라 `null` 입니다. 값을 넣으면 바닥글과 회사 안내에 자동으로 표시됩니다.
- 전화번호를 바꾸면 모든 페이지에 함께 반영됩니다. 다만 자바스크립트가 꺼진 브라우저에 보이는 안내 문구(각 HTML 의 `<noscript>` 줄)와 공유 이미지 설명(`og:image:alt`)에는 번호가 직접 적혀 있으니 함께 바꿔 주세요.

### 첫 화면 사진
- `index.html` 의 `<!-- 첫 화면 -->` 아래 `img` 줄의 `src`·`alt`·`width`·`height` 를 바꾸고, 바로 아래 ‘디자인 예시’ 줄을 지웁니다.

## 6. 보안

- 서버·데이터베이스·로그인이 없어 공격받을 곳이 거의 없고, 업데이트해야 할 외부 라이브러리도 없습니다.
- 모든 HTML 에 **외부 스크립트 차단 설정(Content-Security-Policy)** 이 들어 있습니다. 이 사이트 안의 파일만 불러옵니다.
  나중에 지도 퍼가기·방문 통계 같은 외부 서비스를 넣으려면 이 설정을 함께 바꿔야 합니다. (넣기 전에 개인정보처리방침도 필요)
- 지도 링크는 새 창으로 열리며 원래 페이지를 조작할 수 없게(`noopener`) 되어 있습니다.
- **저장소는 공개되어 있습니다.** 비밀번호, 고객 이름·연락처·주소가 담긴 파일을 절대 올리지 마세요.

## 7. 공개 반영 (GitHub Pages)

`main` 브랜치에 올라간 파일이 그대로 사이트가 됩니다. 빌드 과정이 없습니다.

**바꾼 내용이 바로 안 보일 때**: GitHub Pages 는 파일을 최대 10분간 저장본으로 보여 줍니다.
`css`·`js`·`data` 파일을 고쳤다면 모든 HTML 의 `?v=20261108b` 같은 버전 번호를 새 값으로 한꺼번에 바꿔 주세요.
(VS Code `Ctrl+Shift+H` 로 전체 바꾸기) 그러면 방문자 브라우저가 새 파일을 받습니다.

**처음 한 번만 설정** (이전 Next.js 방식에서 바꾸는 경우):
1. 저장소 → **Settings** → 왼쪽 **Pages**
2. **Build and deployment → Source** 를 **Deploy from a branch** 로 바꿉니다.
3. **Branch** 를 `main`, 폴더를 `/ (root)` 로 고르고 **Save**.
4. 1~3분 뒤 확인용 주소를 엽니다. 진행 상황은 저장소 **Actions** 탭에서 ‘pages build and deployment’ 로 보입니다.

## 8. 정식 공개 전 확인 사항

### 회사에 확인받을 것
| 항목 | 위치 | 현재 상태 |
|---|---|---|
| 회사명·대표전화·휴대전화·주소 | `data/company.js` | 기존 ok114 사이트 기준. 최종 확인 필요 |
| 대표자·사업자등록번호·상담 시간 | `data/company.js` | 비어 있음 (표시 안 됨) |
| 제품명·사진·평면도·크기(기준 포함)·사양·옵션·가격·부가세·포함 범위·판매 여부 | `data/products.js` | 개발용 예시 |
| 제작 기간 안내 (‘빠르면 2주’는 조건과 함께, 확인 후에만) | `data/products.js` → `schedule` | 비어 있음 |
| 실제 제작 방식 설명 | `data/site.js`, `data/company.js` | ‘직접 제작해 운송·설치’로만 표현 |
| 시공 사례 사진·지역·내용 (고객 동의 포함) | `data/cases.js` | 개발용 예시 |
| FAQ 답변 5개 | `data/faq.js` | 초안 |
| 제작·설치 단계가 실제 업무와 맞는지 | `data/process.js` | 기본 흐름 |

**`check.html` 을 열면** 제품별로 비어 있거나 서로 맞지 않는 항목(예: 사진의 옵션 이름이 옵션 목록에 없음)을 한눈에 볼 수 있습니다.

### 정식 공개할 때 바꿀 것
